# Suriyaprakash Sudarvelraja — Professional Portfolio (V3)

A static GitHub Pages portfolio combining a scientific-editorial visual style with the My Path timeline and interactive skills map.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload **all files and folders inside this folder** to the root of `suriyaprakash-16.github.io`.
3. Replace existing files when prompted and commit to the `main` branch.
4. In GitHub, open Settings → Pages and confirm deployment from `main` / root.
5. Wait for the GitHub Pages deployment to complete, then test the live site in a private browser window.

Do not upload only `index.html`: keep `assets/` and `assets/fonts/` intact.

## Files
- `index.html` — page structure and metadata
- `styles.css` — responsive styling, light/dark themes and reduced-motion support
- `script.js` — interactions, navigation, path timeline and skills map
- `content.js` — portfolio content and skill data
- `assets/` — photographs, CV, favicon, social preview and fonts
- `robots.txt`, `sitemap.xml` — crawler guidance
- `UPDATE-GUIDE.md` — how to edit the site without touching code

## Before publishing
- Check the CV is the latest version and contains only contact details you want public.
- Verify email, LinkedIn, CV and blog links.
- Test the menu, theme switch, skill filters and interactive map on mobile.
- Update `sitemap.xml` lastmod when you make substantive site changes.

This package is a static website with no forms. It uses GoatCounter, a privacy-friendly analytics script, to count page views and clicks (CV, email, LinkedIn, blog). To turn analytics off, delete the `<script data-goatcounter...>` line near the bottom of `index.html`.
